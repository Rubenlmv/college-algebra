    Section Section 2.6 Transformation of Graphs

    Subsection Introduction to Parent Functions

    Students should be able to recognize the basic shapes of the graphs of different types of functions.
    🔗
    For instance, you know that the graph of the linear function \(f(x) = mx + b\) is a line with slope \(m\) and \(y\)-intercept at \((0, b)\text{.}\)
    🔗
    🔗

    Subsection Linear Functions

    Definition 89. Linear Function.

    A function of the form \(f(x) = mx + b\) has:
    🔗
    • Domain: all real numbers
      🔗
    • Range: all real numbers
      🔗
    • \(x\)-intercept: \((-b/m, 0)\text{,}\) \(y\)-intercept: \((0, b)\)
      🔗
    • Increasing if \(m > 0\text{,}\) decreasing if \(m < 0\text{,}\) constant if \(m = 0\)
      🔗
    🔗

    Subsection Constant and Identity Functions

    There are two special types of linear functions, the constant function and the identity function.
    🔗
    Definition 93. Constant Function.
    A function of the form \(f(x) = c\) where \(c\) is a constant.
    🔗
    • Domain: all real numbers
      🔗
    • Range: \(\{c\}\)
      🔗
    • Graph is a horizontal line
      🔗
    🔗
    Definition 95. Identity Function.
    A function of the form \(f(x) = x\text{.}\)
    🔗
    • Domain: all real numbers
      🔗
    • Range: all real numbers
      🔗
    • Slope: \(m = 1\)
      🔗
    • \(y\)-intercept: \((0, 0)\)
      🔗
    🔗
    🔗
    🔗

    Subsection Squaring (Quadratic) Functions

    Definition 97. Squaring Function.

    \begin{equation*} f(x) = x^2 \end{equation*}
    🔗
    • Domain: all real numbers
      🔗
    • Range: \([0, \infty)\)
      🔗
    • Even function
      🔗
    • Intercept at \((0, 0)\)
      🔗
    • Decreasing on \((-\infty, 0)\text{,}\) increasing on \((0, \infty)\)
      🔗
    • Symmetric about the \(y\)-axis
      🔗
    🔗
    🔗

    Subsection Cubic Functions

    Definition 99. Cubic Function.

    \begin{equation*} f(x) = x^3 \end{equation*}
    🔗
    • Domain: all real numbers
      🔗
    • Range: all real numbers
      🔗
    • Odd function
      🔗
    • Intercept at \((0, 0)\)
      🔗
    • Increasing on \((-\infty, \infty)\)
      🔗
    • Symmetric about the origin
      🔗
    🔗
    🔗

    Subsection Square Root Functions

    Definition 101. Square Root Function.

    \begin{equation*} f(x) = \sqrt{x} \end{equation*}
    🔗
    • Domain: \([0, \infty)\)
      🔗
    • Range: \([0, \infty)\)
      🔗
    • Intercept at \((0, 0)\)
      🔗
    • Increasing on \((0, \infty)\)
      🔗
    🔗
    🔗

    Subsection Reciprocal Functions

    Definition 103. Reciprocal Function.

    \begin{equation*} f(x) = \frac{1}{x} \end{equation*}
    🔗
    • Domain: \((-\infty, 0) \cup (0, \infty)\)
      🔗
    • Range: \((-\infty, 0) \cup (0, \infty)\)
      🔗
    • Odd function
      🔗
    • No intercepts
      🔗
    • Decreasing on \((-\infty, 0)\) and \((0, \infty)\)
      🔗
    • Symmetric about the origin
      🔗
    🔗
    🔗

    Subsection Step Functions: Greatest Integer Function

    Functions whose graphs resemble sets of stairsteps are known as step functions. The most famous of the step functions is the greatest integer function, denoted by \(\lfloor x \rfloor\) and defined as:
    🔗
    \begin{equation*} f(x) = \lfloor x \rfloor \end{equation*}
    where \(\lfloor x \rfloor\) is the greatest integer less than or equal to \(x\text{.}\)
    🔗
    Some values are:
    🔗
    \begin{equation*} \lfloor -1 \rfloor = -1 \end{equation*}
    \begin{equation*} \lfloor -0.5 \rfloor = -1 \end{equation*}
    \begin{equation*} \lfloor 0.1 \rfloor = 0 \end{equation*}
    \begin{equation*} \lfloor 1.5 \rfloor = 1 \end{equation*}

    Definition 105. Greatest Integer Function.

    \begin{equation*} f(x) = \lfloor x \rfloor \end{equation*}
    🔗
    • Domain: all real numbers
      🔗
    • Range: all integers
      🔗
    • \(y\)-intercept at \((0, 0)\)
      🔗
    • \(x\)-intercepts in \([0, 1)\)
      🔗
    • Constant between consecutive integers
      🔗
    • Jumps vertically one unit at each integer
      🔗
    🔗
    🔗

    Subsection Transformation of Functions — Shifts (Translations)

    Transformation of Functions — Shifts Video
    🔗
    Many functions have graphs that are simple transformations of the parent graphs.
    🔗
    For example, you can obtain the graph of \(h(x) = x^2 + 2\) by shifting the graph of \(f(x) = x^2\) upward two units. The shape of the graph does not change. The graph is simply moved up.
    🔗
    When the shape does not change, the transformation is known as a rigid transformation. In this example we see a vertical translation.
    🔗
    In function notation, \(h\) and \(f\) are related as follows:
    🔗
    \begin{equation*} h(x) = x^2 + 2 = f(x) + 2 \end{equation*}
    • The \(+2\) outside the function changes the \(y\)-values, so the entire graph moves up 2 units.
      🔗
    • The coefficient of \(x^2\) remains \(1\text{,}\) so the parabola keeps the same width and shape.
      🔗
    Similarly, you can obtain the graph of \(g(x) = (x - 2)^2\) by shifting the graph of \(f(x) = x^2\) to the right two units.
    🔗
    In this case, \(g(x) = (x - 2)^2 = f(x - 2)\text{.}\)
    🔗
    • The \(-2\) inside the input shifts the graph right 2 units.
      🔗
    • Horizontal changes occur inside the function and work in the opposite direction of the sign.
      🔗

    Definition 117. Vertical and Horizontal Shifts.

    Let \(h\text{,}\) \(k\) be positive real numbers. Vertical and horizontal shifts in the graph of \(y = f(x)\) are represented as follows.
    🔗
    1. Vertical shift \(k\) units upward: \(h(x) = f(x) + k\)
      🔗
    2. Vertical shift \(k\) units downward: \(h(x) = f(x) - k\)
      🔗
    3. Horizontal shift \(h\) units to the right: \(h(x) = f(x - h)\)
      🔗
    4. Horizontal shift \(h\) units to the left: \(h(x) = f(x + h)\)
      🔗
    🔗

    Example 102.

    Example. Use the graph of \(f(x) = x^3\) to sketch the graph of \(h(x) = (x + 2)^3 + 1\text{.}\)
    🔗
    Solution.
    Relative to the graph of \(f(x) = x^3\text{,}\) the graph of \(h(x) = (x + 2)^3 + 1\) involves a left shift of two units and an upward shift of one unit.
    🔗
    🔗
    🔗
    🔗

    Subsection Transformation of Functions — Reflections

    The second common type of transformation is a reflection.
    🔗
    If you consider the \(x\)-axis to be a mirror, the graph of \(h(x) = -x^2\) is the mirror image (or reflection) of the graph of \(f(x) = x^2\text{,}\) reflected across the \(x\)-axis.
    🔗

    Definition 120. Reflections in the Coordinate Axes.

    Reflections in the coordinate axes of the graph of \(y = f(x)\) are represented as follows.
    🔗
    1. Reflection in the \(x\)-axis: \(h(x) = -f(x)\)
      🔗
    2. Reflection in the \(y\)-axis: \(h(x) = f(-x)\)
      🔗
    🔗
    🔗

    Subsection Non-Rigid Transformations of Functions

    Horizontal shifts, vertical shifts, and reflections are rigid transformations because the basic shape of the graph is unchanged.
    🔗
    These transformations change only the position of the graph in the coordinate plane.
    🔗
    Nonrigid transformations are those that cause a distortion — a change in the shape of the original graph.
    🔗

    Definition 121. Vertical Stretch and Shrink.

    Let \(a\) be a positive real number. Vertical stretch or shrink in the graph of \(y = f(x)\) are represented as follows.
    🔗
    1. Vertical stretch if \(a > 1\text{:}\) \(h(x) = a f(x)\)
      🔗
    2. Vertical shrink if \(0 < a < 1\text{:}\) \(h(x) = a f(x)\)
      🔗
    Parameter \(a\text{:}\) Multiplying the function outside changes vertical height; multiplying \(x\) inside changes horizontal width. Values \(a > 1\) make the graph steeper/narrower, while \(0 < a < 1\) makes it flatter/wider.
    🔗
    🔗

    Definition 122. Horizontal Stretch and Shrink.

    Let \(a\) be a positive real number. Horizontal shrink or stretch in the graph of \(y = f(x)\) are represented as follows.
    🔗
    1. Horizontal shrink if \(a > 1\text{:}\) \(h(x) = f(ax)\)
      🔗
    2. Horizontal stretch if \(0 < a < 1\text{:}\) \(h(x) = f(ax)\)
      🔗
    🔗
    Compare the graph of \(f(x) = |x|\) with the graph of \(h(x) = 3|x|\text{.}\)
    🔗
    Relative to the graph of \(f(x) = |x|\text{,}\) the graph of \(h(x) = 3|x| = 3f(x)\) is a vertical stretch (each \(y\)-value is multiplied by \(3\)) of the graph of \(f\text{.}\)
    🔗
    Compare the graph of \(f(x) = |x|\) with the graph of \(g(x) = \frac{1}{3}|x|\text{.}\)
    🔗
    Relative to the graph of \(f(x) = |x|\text{,}\) the graph of \(g(x) = \frac{1}{3}|x| = \frac{1}{3}f(x)\) is a vertical shrink (each \(y\)-value is multiplied by \(\frac{1}{3}\)) of the graph of \(f\text{.}\)
    🔗

    Definition 125. Order of Transformations.

    If there is more than one transformation, follow this order:
    🔗
    1. Translate the graph horizontally.
      🔗
    2. Stretch or shrink the graph.
      🔗
    3. Reflect the graph across an axis.
      🔗
    4. Translate the graph vertically.
      🔗
    🔗
    🔗

    \begin{equation*} g(x) = \sqrt{x} + 4 \end{equation*}

    Consider the function:
    \begin{equation*} g(x) = |x + 3| - 1 \end{equation*}
    🔗
    1. What is the "Parent Function"?
      🔗
    2. What transformations have been applied?
      🔗

    Example 105.

    Consider the function:
    \begin{equation*} g(x) = -3(x - 2)^2 + 1 \end{equation*}
    🔗
    1. What is the "Parent Function"?
      🔗
    2. What transformations have been applied?
      🔗
    3. Sketch a graph of the Parent function and the transformed function without plotting points.
      🔗
    Solution.
    1. The parent function is \(f(x) = x^2\) (squaring/quadratic function).
    🔗
    2. The transformations are:
    🔗
    • \(h = 2\text{:}\) shift right 2 units
      🔗
    • \(a = -3\text{:}\) reflect across the \(x\)-axis and vertical stretch by 3
      🔗
    • \(k = 1\text{:}\) shift up 1 unit
      🔗
