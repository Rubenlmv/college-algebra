    Section Section 1.7 Inequalities and Absolute Value

    Subsection Inequalities

    Inequalities are solved similarly to equations, but with one important difference: When you multiply or divide both sides of an inequality by a negative number, you must reverse the inequality sign.
    🔗
    For example:
    🔗
    \begin{equation*} -2x < 6 \end{equation*}
    Divide both sides by \(-2\) and reverse the inequality sign:
    🔗
    \begin{equation*} x > -3 \end{equation*}
    🔗

    Subsection Notation for Solutions of Inequalities

    When solving inequalities, there are three ways to represent the solution:
    • Set-Builder Notation — describes the set of all \(x\) that satisfy the condition.
      🔗
    • Interval Notation — uses parentheses \(( \quad )\) and brackets \([ \quad ]\) to describe the interval of solutions.
      🔗
    • Number Line — a visual representation of the solution set.
      🔗
    🔗
    Key Points:
    🔗
    • Parentheses \(( \quad )\) indicate that the endpoint is not included (strict inequalities: \(<\) or \(>\)).
      🔗
    • Brackets \([ \quad ]\) indicate that the endpoint is included (non-strict inequalities: \(\leq\) or \(\geq\)).
      🔗

    Subsubsection Case 1: \(x \leq a\)

    Set-Builder Notation: \(\{x \mid x \leq a\}\)
    🔗

    Subsection Linear Inequalities

    Example 58.

    Problem 1. Solve:
    \begin{equation*} 5(x - 4) > 3x - 8 \end{equation*}
    🔗
    Graph the solution set, and write the solution in set-builder notation and interval notation.
    🔗
    Solution.
    Step 1: Distribute.
    🔗
    \begin{equation*} 5x - 20 > 3x - 8 \end{equation*}
    Step 2: Collect variables on one side.
    🔗
    \begin{equation*} 5x - 3x > -8 + 20 \end{equation*}
    \begin{equation*} 2x > 12 \end{equation*}
    Step 3: Divide by 2.
    🔗
    \begin{equation*} x > 6 \end{equation*}
    Therefore, the solution is \(x > 6\text{.}\)
    🔗
    Set-builder notation: \(\{x \mid x > 6\}\)
    🔗
    Interval notation: \((6, \infty)\)
    🔗
    🔗
    🔗

    Example 59.

    Problem 2. Solve:
    \begin{equation*} 16 \leq 7(x - 3) - 2x + 5 \end{equation*}
    🔗
    Graph the solution set, and write the solution in set-builder notation and interval notation.
    🔗
    Solution.
    Step 1: Distribute and simplify.
    🔗
    \begin{equation*} 16 \leq 7x - 21 - 2x + 5 \end{equation*}
    \begin{equation*} 16 \leq 5x - 16 \end{equation*}
    Step 2: Collect constants on one side.
    🔗
    \begin{equation*} 32 \leq 5x \end{equation*}
    Step 3: Divide by 5.
    🔗
    \begin{equation*} \frac{32}{5} \leq x \end{equation*}
    Therefore, the solution is \(x \geq \frac{32}{5}\text{.}\)
    🔗
    Set-builder notation: \(\left\{x \mid x \geq \frac{32}{5}\right\}\)
    🔗
    Interval notation: \(\left[\frac{32}{5}, \infty\right)\)
    🔗
    🔗
    🔗
    🔗

    Subsection Compound Inequalities

    Compound inequalities involve two separate inequalities joined by or or and.
    🔗

    Problem-Solving Strategy 19.

    Key Differences:
    🔗
    • AND — The solution must satisfy both inequalities.
      🔗
    • OR — The solution must satisfy at least one inequality.
      🔗
    🔗

    Example 60.

    Problem 1 (OR). Solve:
    \begin{equation*} 2x > 10 \quad \text{or} \quad 2x - 3 < 5 \end{equation*}
    🔗
    Graph the solution set, and write the solution in set-builder notation and interval notation.
    🔗
    Solution.
    Solve each inequality separately.
    🔗
    First: \(x > 5\text{.}\) Second: \(x < 4\text{.}\)
    🔗
    Since it is OR, the solution is:
    🔗
    \begin{equation*} x > 5 \quad \text{or} \quad x < 4 \end{equation*}
    Set-builder notation: \(\{x \mid x < 4 \text{ or } x > 5\}\)
    🔗
    Interval notation: \((-\infty, 4) \cup (5, \infty)\)
    🔗
    🔗
    🔗

    Example 61.

    Problem 2 (AND). Solve:
    \begin{equation*} 5x < 10 \quad \text{and} \quad 6x - 12 < 10x \end{equation*}
    🔗
    Graph the solution set, and write the solution in set-builder notation and interval notation.
    🔗
    Solution.
    Solve each inequality separately.
    🔗
    First: \(x < 2\text{.}\) Second: \(-3 < x\text{.}\)
    🔗
    Since it is AND, the solution must satisfy both:
    🔗
    \begin{equation*} -3 < x \quad \text{and} \quad x < 2 \end{equation*}
    Set-builder notation: \(\{x \mid -3 < x < 2\}\)
    🔗
    Interval notation: \((-3, 2)\)
    🔗
    🔗
    🔗

    Example 62.

    Problem 3 (OR). Solve:
    \begin{equation*} \frac{1}{2}x < 3x + 5 \quad \text{or} \quad 6x \geq -12 \end{equation*}
    🔗
    Graph the solution set, and write the solution in set-builder notation and interval notation.
    🔗
    Solution.
    Solve each inequality separately.
    🔗
    First: \(x > -2\text{.}\) Second: \(x \geq -2\text{.}\)
    🔗
    Since it is OR, the solution is:
    🔗
    \begin{equation*} x \geq -2 \end{equation*}
    Set-builder notation: \(\{x \mid x \geq -2\}\)
    🔗
    Interval notation: \([-2, \infty)\)
    🔗
    🔗
    🔗

    Example 63.

    Problem 4 (AND). Solve:
    \begin{equation*} \frac{1}{2}x < 3x + 5 \quad \text{and} \quad 6x \geq -12 \end{equation*}
    🔗
    Graph the solution set, and write the solution in set-builder notation and interval notation.
    🔗
    Solution.
    Solve each inequality separately.
    🔗
    First: \(x > -2\text{.}\) Second: \(x \geq -2\text{.}\)
    🔗
    Since it is AND, the solution must satisfy both:
    🔗
    \begin{equation*} x > -2 \end{equation*}
    Set-builder notation: \(\{x \mid x > -2\}\)
    🔗
    Interval notation: \((-2, \infty)\)

    \begin{equation*} 2 \leq x \leq 6 \end{equation*}

    Subsection Absolute Value: Piecewise Definition

    The absolute value of a number is its distance from zero on the number line.
    🔗
    Piecewise definition:
    🔗
    \begin{equation*} |x| = \begin{cases} x & \text{if } x \geq 0 \\ -x & \text{if } x < 0 \end{cases} \end{equation*}
    🔗

    Subsection Absolute Value Equations

    For \(|X| = k\) where \(k \geq 0\text{,}\) the solutions are:
    🔗
    \begin{equation*} X = k \quad \text{or} \quad X = -k \end{equation*}

    Example 66.

    Problem 1. Solve:
    \begin{equation*} |x| = 5 \end{equation*}
    🔗
    Solution.
    \begin{equation*} x = 5 \quad \text{or} \quad x = -5 \end{equation*}
    Set-builder notation: \(\{x \mid x = -5 \text{ or } x = 5\}\)
    🔗
    Interval notation: \(\{-5, 5\}\)
    🔗
    🔗
    🔗

    Example 67.

    Problem 2. Solve:
    \begin{equation*} |x - 2| = 5 \end{equation*}
    🔗
    Solution.
    \begin{equation*} x - 2 = 5 \quad \text{or} \quad x - 2 = -5 \end{equation*}
    \begin{equation*} x = 7 \quad \text{or} \quad x = -3 \end{equation*}
    Set-builder notation: \(\{x \mid x = -3 \text{ or } x = 7\}\)
    🔗
    Interval notation: \(\{-3, 7\}\)
    🔗
    🔗
    🔗

    Example 68.

    Problem 3. Solve:
    \begin{equation*} \frac{1}{2}|x - 2| + 1 = 5 \end{equation*}
    🔗
    Solution.
    Step 1: Isolate the absolute value.
    🔗
    \begin{equation*} |x - 2| = 8 \end{equation*}
    Step 2: Split into two equations.
    🔗
    \begin{equation*} x = 10 \quad \text{or} \quad x = -6 \end{equation*}
    Set-builder notation: \(\{x \mid x = -6 \text{ or } x = 10\}\)
    🔗
    Interval notation: \(\{-6, 10\}\)
    🔗
    🔗
    🔗

    Example 69.

    Problem 4. Solve:
    \begin{equation*} |2x - 1| = -5 \end{equation*}
    🔗
    Solution.
    No solution. Absolute value cannot equal a negative number.
    🔗
    Set-builder notation: \(\varnothing\)
    🔗
    Interval notation: No solution
    🔗
    🔗
    🔗

    Example 70.

    Problem 5. Solve:
    \begin{equation*} |x - 2| = 0 \end{equation*}
    🔗
    Solution.
    \begin{equation*} x = 2 \end{equation*}
    Set-builder notation: \(\{x \mid x = 2\}\)
    🔗
    Interval notation: \(\{2\}\)
    🔗
    🔗
    🔗
    🔗

    Subsection Absolute Value Inequalities (Less Than or Equal To)

    For \(|X| \leq k\text{,}\) the solution is:
    🔗
    \begin{equation*} -k \leq X \leq k \end{equation*}
    🔗

    Subsection Absolute Value Inequalities (Greater Than or Equal To)

    For \(|X| \geq k\text{,}\) the solution is:
    🔗
    \begin{equation*} X \leq -k \quad \text{or} \quad X \geq k \end{equation*}
    🔗

    Subsection Absolute Value Inequalities (Less Than)

    For \(|X| < k\text{,}\) the solution is:
    🔗
    \begin{equation*} -k < X < k \end{equation*}

    Example 71.

    Problem 1. Solve:
    \begin{equation*} |2x + 3| < 5 \end{equation*}
    🔗
    Solution.
    \begin{equation*} -5 < 2x + 3 < 5 \end{equation*}
    Subtract 3 from all parts.
    🔗
    \begin{equation*} -8 < 2x < 2 \end{equation*}
    Divide by 2.
    🔗
    \begin{equation*} -4 < x < 1 \end{equation*}
    Set-builder notation: \(\{x \mid -4 < x < 1\}\)
    🔗
    Interval notation: \((-4, 1)\)
    🔗
    🔗
    🔗

    Example 72.

    Problem 2. Solve:
    \begin{equation*} |2x + 5| + 4 < 11 \end{equation*}
    🔗
    Solution.
    Isolate the absolute value.
    🔗
    \begin{equation*} |2x + 5| < 7 \end{equation*}
    \begin{equation*} -7 < 2x + 5 < 7 \end{equation*}
    Subtract 5 from all parts.
    🔗
    \begin{equation*} -12 < 2x < 2 \end{equation*}
    Divide by 2.
    🔗
    \begin{equation*} -6 < x < 1 \end{equation*}
    Set-builder notation: \(\{x \mid -6 < x < 1\}\)
    🔗
    Interval notation: \((-6, 1)\)
    🔗
    🔗
    🔗
    🔗

    Subsection Absolute Value Inequalities (Greater Than)

    For \(|X| > k\text{,}\) the solution is:
    🔗
    \begin{equation*} X < -k \quad \text{or} \quad X > k \end{equation*}

    Example 73.

    Problem 1. Solve:
    \begin{equation*} |2x + 3| \geq 5 \end{equation*}
    🔗
    Solution.
    \begin{equation*} 2x + 3 \leq -5 \quad \text{or} \quad 2x + 3 \geq 5 \end{equation*}
    First: \(x \leq -4\text{.}\) Second: \(x \geq 1\text{.}\)
    🔗
    Set-builder notation: \(\{x \mid x \leq -4 \text{ or } x \geq 1\}\)
    🔗
    Interval notation: \((-\infty, -4] \cup [1, \infty)\)
    🔗
    🔗
    🔗

    Example 74.

    Problem 2. Solve:
    \begin{equation*} 2|x + 4| + 3 > 9 \end{equation*}
    🔗
    Solution.
    Isolate the absolute value.
    🔗
    \begin{equation*} |x + 4| > 3 \end{equation*}
    First: \(x < -7\text{.}\) Second: \(x > -1\text{.}\)
    🔗
    Set-builder notation: \(\{x \mid x < -7 \text{ or } x > -1\}\)
    🔗
    Interval notation: \((-\infty, -7) \cup (-1, \infty)\)
    🔗
