    Section Section 3.1 Quadratic Functions

    Subsection Quadratic Functions

    Definition 153. Quadratic Function.

    A quadratic function is a function that can be written in the form
    🔗
    \begin{equation*} f(x) = ax^2 + bx + c, \quad a \neq 0 \end{equation*}
    That is, it is an equation of degree 2.
    🔗
    🔗
    The Graph of a Quadratic Function Video
    🔗
    The graph of a quadratic function is a parabola.
    🔗
    🔗

    Subsection Vertex (Standard Form)

    Definition 156. Vertex Form.

    The function may be written in vertex form as
    🔗
    \begin{equation*} f(x) = a(x - h)^2 + k \end{equation*}
    In this case, the vertex is at the point \((h, k)\text{.}\)
    🔗
    Notice:
    🔗
    • The function is written as \((x - h)\text{.}\)
      🔗
    • Axis of symmetry: \(x = h\text{.}\)
      🔗
    🔗
    🔗

    Subsection You Try: Example

    Example 121.

    Graph the quadratic function
    \begin{equation*} f(x) = (x - 2)^2 - 3 \end{equation*}
    🔗
    Identify the vertex, \(x\)- and \(y\)-intercepts, and axis of symmetry.
    🔗
    Solution.
    Vertex: \((2, -3)\)
    🔗
    Axis of symmetry: \(x = 2\)
    🔗
    \(x\)-intercepts: \((2 \pm \sqrt{3}, 0)\) ≈ \((0.268, 0)\) and \((3.732, 0)\)
    🔗
    \(y\)-intercept: \((0, 1)\)
    🔗
    🔗
    🔗
    🔗

    Subsection The Vertex Formula

    The Vertex Formula Video
    🔗

    Definition 163. Vertex Formula.

    For \(f(x) = ax^2 + bx + c\text{,}\) \(a \neq 0\text{,}\) the \(x\)-coordinate of the vertex is:
    🔗
    \begin{equation*} x = -\frac{b}{2a} \end{equation*}
    The \(y\)-coordinate is \(f\left(-\frac{b}{2a}\right)\text{.}\)
    🔗
    🔗
    Example: For \(f(x) = 2x^2 + 20x + 42\text{:}\)
    🔗
    \begin{equation*} x = -\frac{20}{2(2)} = -5 \end{equation*}
    \begin{equation*} f(-5) = 2(-5)^2 + 20(-5) + 42 = -8 \end{equation*}
    Vertex: \((-5, -8)\)
    🔗
    🔗

    Subsection You Try: Example

    Example 125.

    Given \(f(x) = -2x^2 - 4x + 3\text{,}\) find the vertex by:
    🔗
    1. Completing the square
      🔗
    2. The vertex formula
      🔗
    Solution.
    Method 1: Completing the Square
    🔗
    \begin{equation*} f(x) = -2(x + 1)^2 + 5 \end{equation*}
    Vertex: \((-1, 5)\)
    🔗
    Method 2: Vertex Formula
    🔗
    \begin{equation*} x = -\frac{-4}{2(-2)} = -1 \end{equation*}
    \begin{equation*} f(-1) = -2(-1)^2 - 4(-1) + 3 = 5 \end{equation*}
    Vertex: \((-1, 5)\)
    🔗
    🔗
