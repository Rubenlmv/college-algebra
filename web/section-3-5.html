    Subsection Rational Functions

    Functions in the form:
    \begin{equation*} R(x) = \frac{P(x)}{Q(x)} \end{equation*}
    where \(P(x)\) and \(Q(x)\) are polynomials.

    Subsection Example: Infinite Behavior

    Example 146.

    The graph of \(f(x) = \dfrac{x - 1}{x - 3}\) is shown below. Complete the statements.
    🔗
    As \(x \to \infty\text{,}\) \(f(x) \to\) _____
    🔗
    As \(x \to -\infty\text{,}\) \(f(x) \to\) _____
    🔗
    As \(x \to 3^+\text{,}\) \(f(x) \to\) _____
    🔗
    As \(x \to 3^-\text{,}\) \(f(x) \to\) _____
    🔗
    Solution.
    • As \(x \to \infty\text{,}\) \(f(x) \to 1\) (horizontal asymptote).
      🔗
    • As \(x \to -\infty\text{,}\) \(f(x) \to 1\) (horizontal asymptote).
      🔗
    • As \(x \to 3^+\text{,}\) \(f(x) \to \infty\) (vertical asymptote, right side).
      🔗
    • As \(x \to 3^-\text{,}\) \(f(x) \to -\infty\) (vertical asymptote, left side).
      🔗
    🔗
    🔗
    🔗

    Subsection Vertical Asymptotes

    Definition 218. Vertical Asymptote.

    The line \(x = c\) is a vertical asymptote of the graph of \(f\) if \(f(x)\) approaches \(\infty\) or \(-\infty\) as \(x\) approaches \(c\) from either side.
    🔗
    🔗
    Identifying vertical asymptotes: Let \(R(x)=\frac{P(x)}{Q(x)}\) with no common factors. The vertical asymptotes occur at the real zeros of \(Q(x)\) that are not zeros of \(P(x)\text{.}\)
    🔗

    Example 147.

    Identify the vertical asymptotes (if any) of: \(f(x) = \dfrac{x - 3}{x^2 - 4x - 5}\)
    🔗
    Solution.
    Factor the denominator:
    \begin{equation*} x^2 - 4x - 5 = (x - 5)(x + 1). \end{equation*}
    Set equal to zero:
    \begin{equation*} (x - 5)(x + 1) = 0 \implies x = 5,\; x = -1. \end{equation*}
    Since neither zero cancels with the numerator, both are vertical asymptotes.
    🔗
    🔗
    🔗
    VA Exception to the Rule Video
    🔗

    Example 148.

    Identify the vertical asymptotes (if any) of: \(f(x) = \dfrac{x - 3}{x^2 - 2x - 3}\)
    🔗
    Solution.
    Factor the denominator:
    \begin{equation*} x^2 - 2x - 3 = (x - 3)(x + 1). \end{equation*}
    The common factor \((x-3)\) cancels with the numerator, leaving:
    \begin{equation*} f(x) = \frac{1}{x+1},\quad x \neq 3. \end{equation*}
    So there is a hole at \(x=3\text{.}\) The y‑value of the hole is
    \begin{equation*} \frac{1}{3+1} = \frac{1}{4}. \end{equation*}
    The vertical asymptote is \(x = -1\text{.}\)
    🔗
    🔗
    🔗

    Example 149.

    Identify the vertical asymptotes (if any) of: \(f(x) = \dfrac{8}{x^2 + 25}\)
    🔗
    Solution.
    The denominator \(x^2 + 25 = 0\) has no real solutions, so there are no vertical asymptotes.
    🔗
    🔗
    🔗
    🔗

    Subsection Horizontal Asymptotes

    Definition 226. Horizontal Asymptote.

    The line \(y = d\) is a horizontal asymptote if \(f(x) \to d\) as \(x \to \infty\) or \(x \to -\infty\text{.}\) This is the end‑behavior of rational functions.
    🔗
    🔗
    For a rational function
    \begin{equation*} f(x)=\frac{a_n x^n + \cdots}{b_m x^m + \cdots} \end{equation*}
    with \(n\) = degree of numerator, \(m\) = degree of denominator:
    🔗
    • If \(n > m\text{,}\) no horizontal asymptote.
      🔗
    • If \(n < m\text{,}\) horizontal asymptote \(y=0\text{.}\)
      🔗
    • If \(n = m\text{,}\) horizontal asymptote \(y=\frac{a_n}{b_m}\text{.}\)
      🔗
    Note: The graph of a rational function may cross a horizontal asymptote (unlike vertical asymptotes, which it cannot cross).
    🔗

    Example 150.

    Identify the asymptotes (if any) of \(f(x)=\dfrac{3x}{x^2-9}\text{.}\)
    🔗
    Solution.
    Vertical asymptotes: \(x=3\) and \(x=-3\) (from \(x^2-9=0\)). Horizontal asymptote: degree numerator = 1, denominator = 2 → \(n < m\) → \(y=0\text{.}\)
    🔗
    🔗
    🔗

    Example 151.

    Identify the asymptotes (if any) of \(f(x)=\dfrac{3x^2}{x^2-9}\text{.}\)
    🔗
    Solution.
    Vertical asymptotes: \(x=3\) and \(x=-3\text{.}\) Horizontal asymptote: degrees equal → \(y = \frac{3}{1} = 3\text{.}\)
    🔗
    🔗
    🔗
    🔗

    Subsection Slant (Oblique) Asymptotes

    A rational function has a slant asymptote if the degree of the numerator is exactly one greater than the degree of the denominator. To find it, divide the numerator by the denominator; the quotient (linear) is the slant asymptote.
    🔗

    Example 152.

    Find the slant asymptote of \(f(x)=\dfrac{3x^3}{x^2-9}\text{.}\)
    🔗
    Solution.
    Divide \(3x^3\) by \(x^2-9\text{:}\)
    🔗
    The quotient is \(3x\text{,}\) so the slant asymptote is \(y = 3x\text{.}\)
    🔗
    🔗
    🔗
    🔗

    Subsection Graphing a Rational Function

    Graphing a Rational Function Summary Video
    🔗

    Problem-Solving Strategy 235. Graphing Rational Functions.

    Given \(f(x)=\frac{P(x)}{Q(x)}\) where \(P(x)\) and \(Q(x)\) are polynomials with no common factors:
    🔗
    Step 1: Factor.
    🔗
    Begin by factoring the numerator and denominator.
    🔗
    Holes:
    🔗
    When you factor the top and bottom, if you notice a common factor that can simplify as a one, please do so. However note at what x-value this is, because your graph will have a hole at that input. To find the point at which the hole occurs, plug in that x value into the simplified function.
    🔗
    Intercepts:
    🔗
    • To find the \(x\)-intercepts, solve \(f(x) = 0\text{.}\) Notice that if you "clear the fraction", you only need solve \(0 = P(x)\text{.}\)
      🔗
    • To find the \(y\)-intercept, evaluate \(f(0)\text{.}\)
      🔗
    Asymptotes:
    🔗
    • Vertical asymptotes: solve \(0 = Q(x)\) (after canceling common factors).
      🔗
    • Horizontal asymptote: use the degree rules.
      🔗
    • Slant asymptote: if degree numerator = degree denominator + 1.
      🔗
    Sketch:
    🔗
    • Put intercepts and asymptotes on the graph.
      🔗
    • Plot points (ALEKS will ask for one or two points on each part of the graph).
      🔗
    • Complete the sketch using all collected information.
      🔗
    🔗

    Example 153.

    Sketch a graph of \(f(x)=\dfrac{x^2-x-6}{x^2-5x-6}\text{.}\)
    🔗
    Solution.
    Step 1: Factor.
    🔗
    \begin{equation*} f(x)=\frac{x^2-x-6}{x^2-5x-6}=\frac{(x-3)(x+2)}{(x-6)(x+1)} \end{equation*}
    No common factors → no holes.
    🔗
    Step 2: Intercepts.
    🔗
    • \(x\)-intercepts: \(0=(x-3)(x+2)\) → \(x=-2,\;3\text{.}\)
      🔗
    • \(y\)-intercept: \(f(0)=\frac{0^2-0-6}{0^2-5(0)-6}=1\text{.}\)
      🔗
    Step 3: Asymptotes.
    🔗
    • Vertical asymptotes: \(0=(x-6)(x+1)\) → \(x=6,\;-1\text{.}\)
      🔗
    • Horizontal asymptote: degrees equal → \(y=1\text{.}\)
      🔗
    🔗
    🔗
    🔗

    Subsection You Try: Graphing a Rational Function

    Example 154.

    Sketch a graph of \(f(x)=\dfrac{2x^2}{x^2-4}\text{.}\)
    🔗
    Solution.
    Step 1: Factor.
    🔗
    \begin{equation*} f(x)=\frac{2x^2}{x^2-4}=\frac{2x^2}{(x-2)(x+2)} \end{equation*}
    No common factors.
    🔗
    Step 2: Intercepts.
    🔗
    • \(x\)-intercepts: \(0=2x^2\) → \(x=0\text{.}\)
      🔗
    • \(y\)-intercept: \(f(0)=0\text{.}\)
      🔗
    Step 3: Asymptotes.
    🔗
    • Vertical asymptotes: \(0=(x-2)(x+2)\) → \(x=2,\;-2\text{.}\)
      🔗
    • Horizontal asymptote: degrees equal → \(y=2\text{.}\)
      🔗
    🔗
    🔗
    🔗

    Subsection Example: Graphing with a Slant Asymptote

    Example 155.

    Sketch a graph of \(f(x)=\dfrac{2x^2-8x+8}{x-3}\text{.}\)
    🔗
    Solution.
    Step 1: Factor.
    🔗
    \begin{equation*} f(x)=\frac{2x^2-8x+8}{x-3}=\frac{2(x-2)^2}{x-3} \end{equation*}
    No common factors.
    🔗
    Step 2: Intercepts.
    🔗
    • \(x\)-intercepts: \(0=2(x-2)^2\) → \(x=2\text{.}\)
      🔗
    • \(y\)-intercept: \(f(0)=\frac{8}{-3}=-\frac{8}{3}\text{.}\)
      🔗
    Step 3: Asymptotes.
    🔗
    • Vertical asymptote: \(0=x-3\) → \(x=3\text{.}\)
      🔗
    • No horizontal asymptote (degree numerator > degree denominator).
      🔗
    • Slant asymptote: divide \(2x^2-8x+8\) by \(x-3\) → \(2x-2\text{.}\)
      🔗
    🔗
