    Section Section 2.8 Algebra and Composition of Functions

    Subsection Operations on Functions

    Operations on Functions Video
    🔗
    In business, we can define the Cost Function \(C(x) = mx + b\text{,}\) where \(x\) is the units produced, \(m\) is the unit cost and \(b\) is the fixed cost. Further, we define the Revenue function as \(R(x) = px\) where \(p\) is the selling price. Finally, we know profit is Revenue minus Cost, in other words, \(P(x) = R(x) - C(x)\text{.}\) We have created a "new" function by algebraically combining two functions.
    🔗

    Definition 145. Sum, Difference, Product, and Quotient of Functions.

    Let \(f\) and \(g\) be functions with overlapping domains. Then:
    🔗
    • Sum:
      \begin{equation*} (f + g)(x) = f(x) + g(x) \end{equation*}
      🔗
    • Difference:
      \begin{equation*} (f - g)(x) = f(x) - g(x) \end{equation*}
      🔗
    • Product:
      \begin{equation*} (fg)(x) = f(x)g(x) \end{equation*}
      🔗
    • Quotient:
      \begin{equation*} \left(\frac{f}{g}\right)(x) = \frac{f(x)}{g(x)}, \quad g(x) \neq 0 \end{equation*}
      🔗
    🔗

    Example 114.

    Let \(f(x) = x^2 + 1\) and \(g(x) = 2x - 3\text{.}\) Find:
    🔗
    1. \((f + g)(x)\)
    🔗
    2. \((f - g)(x)\)
    🔗
    3. \((fg)(x)\)
    🔗
    4. \(\left(\frac{f}{g}\right)(x)\)
    🔗
    5. \((f + g)(2)\)
    🔗
    6. \(f(2) + g(2)\)
    🔗
    Solution.
    1. \((f + g)(x) = (x^2 + 1) + (2x - 3) = x^2 + 2x - 2\)
    🔗
    2. \((f - g)(x) = (x^2 + 1) - (2x - 3) = x^2 - 2x + 4\)
    🔗
    3. \((fg)(x) = (x^2 + 1)(2x - 3) = 2x^3 - 3x^2 + 2x - 3\)
    🔗
    4. \(\left(\frac{f}{g}\right)(x) = \frac{x^2 + 1}{2x - 3}, \quad x \neq \frac{3}{2}\)
    🔗
    5. \((f + g)(2) = 2^2 + 2(2) - 2 = 4 + 4 - 2 = 6\)
    🔗
    6. \(f(2) + g(2) = (4 + 1) + (4 - 3) = 5 + 1 = 6\)
    🔗
    Notice that \((f + g)(2) = f(2) + g(2)\text{,}\) as expected.
    🔗
    🔗
    🔗

    Example 115.

    Let \(f(x) = x^2 + 1\text{,}\) \(g(x) = 2x - 3\text{,}\) and \(h(x) = x\text{.}\) Find:
    🔗
    1. \((f - g)(x)\)
    🔗
    2. \((fg)(x)\)
    🔗
    3. \(\left(\frac{f}{g}\right)(x)\)
    🔗
    4. \(\left(\frac{f}{g}\right)(3)\)
    🔗
    5. \(\frac{f(3)}{g(3)}\)
    🔗
    6. \((fh)(x)\)
    🔗
    Solution.
    1. \((f - g)(x) = (x^2 + 1) - (2x - 3) = x^2 - 2x + 4\)
    🔗
    2. \((fg)(x) = (x^2 + 1)(2x - 3) = 2x^3 - 3x^2 + 2x - 3\)
    🔗
    3. \(\left(\frac{f}{g}\right)(x) = \frac{x^2 + 1}{2x - 3}, \quad x \neq \frac{3}{2}\)
    🔗
    4. \(\left(\frac{f}{g}\right)(3) = \frac{3^2 + 1}{2(3) - 3} = \frac{10}{3}\)
    🔗
    5. \(\frac{f(3)}{g(3)} = \frac{10}{3}\)
    🔗
    6. \((fh)(x) = (x^2 + 1)(x) = x^3 + x\)
    🔗
    🔗

    Subsection Difference Quotient

    Difference Quotient Video
    🔗
    The average rate of change between \(P\) and \(Q\) is the slope of the secant line and is given by:
    🔗
    \begin{equation*} m = \frac{\Delta y}{\Delta x} = \frac{f(x + h) - f(x)}{(x + h) - x} = \frac{f(x + h) - f(x)}{h} \end{equation*}
    The expression
    \begin{equation*} \frac{f(x + h) - f(x)}{h} \end{equation*}
    is called the difference quotient.
    🔗
    Notice how similar this is to "Average Rate of Change." It provides a formula for the average rate of change between \(x\) and \(x + h\text{.}\)
    🔗

    Example 116.

    Find \(\dfrac{f(x + h) - f(x)}{h}\) for \(f(x) = 5x - 3\text{.}\)
    🔗
    Describe the graph of \(f(x)\text{.}\) How does this agree with what you found for the difference quotient?
    🔗
    Solution.
    Step 1: Find \(f(x + h)\text{.}\)
    🔗
    \begin{equation*} f(x + h) = 5(x + h) - 3 = 5x + 5h - 3 \end{equation*}
    Step 2: Substitute into the difference quotient.
    🔗
    \begin{equation*} \frac{f(x + h) - f(x)}{h} = \frac{(5x + 5h - 3) - (5x - 3)}{h} = \frac{5h}{h} = 5 \end{equation*}
    The graph of \(f(x) = 5x - 3\) is a line with slope \(m = 5\text{.}\) The difference quotient gives the slope \(5\text{,}\) which matches the slope of the line.
    🔗
    🔗
    🔗

    Example 117.

    Find \(\dfrac{f(x + h) - f(x)}{h}\) for \(f(x) = x^2 - 3x + 2\text{.}\)
    🔗
    Consider what happens as \(h \to 0\text{.}\) Describe what that means.
    🔗
    Solution.
    Step 1: Find \(f(x + h)\text{.}\)
    🔗
    \begin{equation*} f(x + h) = (x + h)^2 - 3(x + h) + 2 \end{equation*}
    \begin{equation*} f(x + h) = x^2 + 2xh + h^2 - 3x - 3h + 2 \end{equation*}
    Step 2: Substitute into the difference quotient.
    🔗
    \begin{equation*} \frac{f(x + h) - f(x)}{h} = \frac{(x^2 + 2xh + h^2 - 3x - 3h + 2) - (x^2 - 3x + 2)}{h} \end{equation*}
    \begin{equation*} = \frac{2xh + h^2 - 3h}{h} = 2x + h - 3 \end{equation*}
    Step 3: Consider what happens as \(h \to 0\text{.}\)
    🔗
    \begin{equation*} \lim_{h \to 0} \frac{f(x + h) - f(x)}{h} = \lim_{h \to 0} (2x + h - 3) = 2x - 3 \end{equation*}
    As \(h \to 0\text{,}\) the secant line approaches the tangent line to the parabola at the point \((x, f(x))\text{.}\) The difference quotient approaches the instantaneous rate of change (the derivative) at that point. For \(f(x) = x^2 - 3x + 2\text{,}\) the derivative is \(f'(x) = 2x - 3\text{,}\) which gives the slope of the tangent line at any point \(x\text{.}\)
    🔗
    🔗
    🔗
    🔗

    Subsection Composition of Functions

    Composition of Functions Video
    🔗
    You are ready to purchase the 3-D big screen television. But, the price is \(\$1000\text{.}\) Lucky for you, two stores have the television you want on SALE! And even better, it’s a super, double discount sale.
    🔗
    Store A: Price reduced by \(\$200\) and take an additional \(20\%\) off the already low price.
    🔗
    Store B: \(20\%\) off PLUS take an additional \(\$200\) off the discounted price.
    🔗
    Are the prices the same? If not, which store has the better sale?
    🔗
    For Store A:
    🔗
    \begin{equation*} f(x) = x - 200, \quad g(x) = x - 0.2x = 0.8x \end{equation*}
    \begin{equation*} g(f(1000)) = (1000 - 200) - 0.2(1000 - 200) = 800 - 160 = \$640 \end{equation*}
    For Store B:
    🔗
    \begin{equation*} f(x) = x - 0.2x = 0.8x, \quad g(x) = x - 200 \end{equation*}
    \begin{equation*} g(f(1000)) = (1000 - 0.2(1000)) - 200 = 800 - 200 = \$600 \end{equation*}
    The prices are not the same. Store B has the better sale by \(\$40\text{.}\)
    🔗

    Definition 151. Composition of Functions.

    The composition of \(f\) and \(g\text{,}\) denoted \((f \circ g)(x)\text{,}\) is defined as:
    🔗
    \begin{equation*} (f \circ g)(x) = f(g(x)) \end{equation*}
    The domain of \(f \circ g\) is the set of all \(x\) in the domain of \(g\) such that \(g(x)\) is in the domain of \(f\text{.}\)
    🔗
    🔗

    Example 118.

    Let \(f(x) = x^2 + 2x + 1\) and \(g(x) = x - 3\text{.}\) Evaluate and simplify:
    🔗
    1. \((f \circ g)(x)\)
    🔗
    2. \((g \circ f)(x)\)
    🔗
    Solution.
    1. \((f \circ g)(x) = f(g(x))\)
    🔗
    \begin{equation*} f(g(x)) = f(x - 3) = (x - 3)^2 + 2(x - 3) + 1 \end{equation*}
    \begin{equation*} f(g(x)) = (x^2 - 6x + 9) + (2x - 6) + 1 \end{equation*}
    \begin{equation*} f(g(x)) = x^2 - 4x + 4 = (x - 2)^2 \end{equation*}
    2. \((g \circ f)(x) = g(f(x))\)
    🔗
    \begin{equation*} g(f(x)) = g(x^2 + 2x + 1) = (x^2 + 2x + 1) - 3 \end{equation*}
    \begin{equation*} g(f(x)) = x^2 + 2x - 2 \end{equation*}
    🔗
    🔗

    Subsection Decomposition of Functions

    Decomposition Video
    🔗
    The process of finding two functions whose composition is the original function is called decomposition.
    🔗

    Example 119.

    Given \(h(x) = \sqrt{x + 2}\text{,}\) find functions \(f(x)\) and \(g(x)\) such that \((f \circ g)(x) = h(x)\text{.}\)
    🔗
    Solution.
    We need to decompose \(h(x)\) into two functions. Let:
    🔗
    \begin{equation*} g(x) = x + 2, \quad f(x) = \sqrt{x} \end{equation*}
    Then:
    🔗
    \begin{equation*} (f \circ g)(x) = f(g(x)) = f(x + 2) = \sqrt{x + 2} = h(x) \end{equation*}
    Therefore, \(f(x) = \sqrt{x}\) and \(g(x) = x + 2\text{.}\)
    🔗
    🔗
    🔗

    Example 120.

    Given \(h(x) = (2x - 4)^3\text{,}\) find functions \(f(x)\) and \(g(x)\) such that \((f \circ g)(x) = h(x)\text{.}\)
    🔗
    Solution.
    We need to decompose \(h(x)\) into two functions. Let:
    🔗
    \begin{equation*} g(x) = 2x - 4, \quad f(x) = x^3 \end{equation*}
    Then:
    🔗
    \begin{equation*} (f \circ g)(x) = f(g(x)) = f(2x - 4) = (2x - 4)^3 = h(x) \end{equation*}
    Therefore, \(f(x) = x^3\) and \(g(x) = 2x - 4\text{.}\)
    🔗
    🔗
    🔗

    Subsection Using Graphs for Function Operations

    Use the graphs of \(f(x)\) and \(g(x)\) below to find:
    🔗
    1. \((f - g)(3)\)
    🔗
    2. \((fg)(-1)\)
    🔗
    3. \((f \circ g)(-1)\)
    🔗
    4. \((g \circ f)(-1)\)
    🔗
    5. \((f \circ g)(0)\)
    🔗
    Solution.
    From the graph:
    🔗
    \(f(-1) = 2\text{,}\) \(g(-1) = -4\text{,}\) \(f(3) = 4.5\) (approximately), \(g(3) = 1\) (approximately), \(f(0) = 2\text{,}\) \(g(0) = -3\)
    🔗
    1. \((f - g)(3) = f(3) - g(3) = 4.5 - 1 = 3.5\)
    🔗
    2. \((fg)(-1) = f(-1)g(-1) = 2(-4) = -8\)
    🔗
    3. \((f \circ g)(-1) = f(g(-1)) = f(-4) \approx -2\)
    🔗
    4. \((g \circ f)(-1) = g(f(-1)) = g(2) \approx 4\)
    🔗
    5. \((f \circ g)(0) = f(g(0)) = f(-3) \approx -1\)
