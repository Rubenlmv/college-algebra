    Subsection Quadratic Equations

    You should know how to solve quadratic equations by:
    🔗
    • Zero Product Property (aka factoring)
      🔗
    • Square Root Property (apply square root to both sides when appropriate)
      🔗
    • Completing the Square (this WILL be on the test)
      🔗
    • The Quadratic Formula (a student favorite and most often done wrong)
      🔗

    🔗
    🔗

    Subsection The Zero Product Property

    If \(mn = 0\text{,}\) then \(m = 0\) or \(n = 0\text{.}\)
    🔗
    That is, if the product of two factors is zero, then at least one factor is zero.
    🔗
    The big idea is: if we find a value that makes one factor equal to zero, the value of the other factor doesn’t matter.
    🔗

    Example 37.

    Solve:
    \begin{equation*} 2x = 0 \end{equation*}
    🔗
    Solution.
    \begin{equation*} x = 0 \end{equation*}
    🔗
    🔗

    Example 38.

    Solve:
    \begin{equation*} 2(x - 1) = 0 \end{equation*}
    🔗
    Solution.
    \begin{equation*} x - 1 = 0 \end{equation*}
    \begin{equation*} x = 1 \end{equation*}
    🔗
    🔗

    Example 39.

    Solve:
    \begin{equation*} x(x - 1) = 0 \end{equation*}
    🔗
    Solution.
    \begin{equation*} x = 0 \quad \text{or} \quad x - 1 = 0 \end{equation*}
    \begin{equation*} x = 0 \quad \text{or} \quad x = 1 \end{equation*}
    🔗
    🔗
    Notice that we find values for \(x\) where the factor is equal to zero. Zero is like "magic", since anything times zero is ZERO.
    🔗
    🔗

    Subsection Practice: Factoring

    Solve each equation by factoring:
    🔗
    Factoring Trinomials Trick: Trick Video
    🔗

    Example 40.

    \begin{equation*} x(2x + 1) = 15 \end{equation*}
    🔗
    Solution.
    First, rewrite in standard form:
    🔗
    \begin{equation*} 2x^2 + x - 15 = 0 \end{equation*}
    \begin{equation*} (2x - 5)(x + 3) = 0 \end{equation*}
    \begin{equation*} 2x - 5 = 0 \quad \text{or} \quad x + 3 = 0 \end{equation*}
    \begin{equation*} x = \frac{5}{2} \quad \text{or} \quad x = -3 \end{equation*}
    🔗
    🔗

    Example 41.

    \begin{equation*} 24x^2 = 8x \end{equation*}
    🔗
    Solution.
    \begin{equation*} 24x^2 - 8x = 0 \end{equation*}
    \begin{equation*} 8x(3x - 1) = 0 \end{equation*}
    \begin{equation*} 8x = 0 \quad \text{or} \quad 3x - 1 = 0 \end{equation*}
    \begin{equation*} x = 0 \quad \text{or} \quad x = \frac{1}{3} \end{equation*}
    🔗
    🔗

    Example 42.

    Solve using the trick from the video above:
    \begin{equation*} 6x^2 + 23x - 4 = 0 \end{equation*}
    🔗
    Solution.
    \begin{equation*} (6x - 1)(x + 4) = 0 \end{equation*}
    \begin{equation*} 6x - 1 = 0 \quad \text{or} \quad x + 4 = 0 \end{equation*}
    \begin{equation*} x = \frac{1}{6} \quad \text{or} \quad x = -4 \end{equation*}
    🔗
    🔗
    🔗

    Example 43.

    \begin{equation*} 3x^2 = 12 \end{equation*}
    🔗

    \begin{equation*} x^2 + 25 = 0 \end{equation*}
    🔗

    \begin{equation*} x^2 = -25 \end{equation*}
    \begin{equation*} x = \pm \sqrt{-25} = \pm 5i \end{equation*}

    Example 45.

    \begin{equation*} (x - 5)^2 = 7 \end{equation*}
    🔗
    Solution.
    \begin{equation*} x - 5 = \pm \sqrt{7} \end{equation*}
    \begin{equation*} x = 5 \pm \sqrt{7} \end{equation*}

    Subsection Completing the Square

    To solve \(ax^2 + bx + c = 0\) by completing the square, you want to get the equation in the form:
    🔗
    \begin{equation*} (\text{something})^2 = \text{constant} \end{equation*}

    Problem-Solving Strategy 5.

    Steps for Completing the Square:
    🔗
    1. Divide both sides by \(a\) to make the leading coefficient 1.
      🔗
    2. Isolate the variable terms on one side of the equation.
      🔗
    3. Complete the square. Add the square of one-half the linear term to both sides. That is, add \(\left(\frac{b}{2}\right)^2\) to both sides, then factor.
      🔗
    4. Apply the square root property and solve for \(x\text{.}\)
      🔗
    🔗
    Completing the Square Video
    🔗
    Completing the Square Example Video
    🔗

    Example 46.

    \begin{equation*} x^2 - 18x + 5 = 0 \end{equation*}
    🔗
    Solution.
    Step 1: The leading coefficient is already 1.
    🔗
    Step 2: Isolate the variable terms:
    🔗
    \begin{equation*} x^2 - 18x = -5 \end{equation*}
    Step 3: Complete the square. \(\left(\frac{-18}{2}\right)^2 = (-9)^2 = 81\)
    🔗
    \begin{equation*} x^2 - 18x + 81 = -5 + 81 \end{equation*}
    \begin{equation*} (x - 9)^2 = 76 \end{equation*}
    Step 4: Apply the square root property:
    🔗
    \begin{equation*} x - 9 = \pm \sqrt{76} = \pm 2\sqrt{19} \end{equation*}
    \begin{equation*} x = 9 \pm 2\sqrt{19} \end{equation*}
    🔗
    🔗

    Subsection The Quadratic Formula

    For \(ax^2 + bx + c = 0\text{,}\) the solutions are:
    🔗
    \begin{equation*} x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a} \end{equation*}
    The Quadratic Formula Video
    🔗

    Example 47.

    Solve using the quadratic formula:
    🔗
    \begin{equation*} 2x(x - 3) = -7 \end{equation*}
    (Rewrite as \(ax^2 + bx + c = 0\text{.}\) What are the values for \(a, b\) and \(c\text{?}\))
    🔗
    Solution.
    First, rewrite as \(ax^2 + bx + c = 0\text{:}\)
    🔗
    \begin{equation*} 2x^2 - 6x + 7 = 0 \end{equation*}
    So \(a = 2\text{,}\) \(b = -6\text{,}\) \(c = 7\text{.}\)
    🔗
    \begin{equation*} x = \frac{-(-6) \pm \sqrt{(-6)^2 - 4(2)(7)}}{2(2)} \end{equation*}
    \begin{equation*} x = \frac{6 \pm \sqrt{36 - 56}}{4} \end{equation*}
    \begin{equation*} x = \frac{6 \pm \sqrt{-20}}{4} = \frac{6 \pm 2i\sqrt{5}}{4} \end{equation*}
    \begin{equation*} x = \frac{3 \pm i\sqrt{5}}{2} \end{equation*}
    🔗
    🔗

    Subsection The Discriminant

    The discriminant is the expression under the radical in the quadratic formula:
    🔗
    \begin{equation*} D = b^2 - 4ac \end{equation*}
    It describes the type of solutions the quadratic equation will have:
    🔗
    • \(b^2 - 4ac > 0\) — then there are 2 real solutions.
      🔗
    • \(b^2 - 4ac = 0\) — then there is only one square root of zero, so there is 1 real solution.
      🔗
    • \(b^2 - 4ac < 0\) — then there are 2 imaginary roots, so there are 2 complex solutions.
      🔗
    Discriminant Video
    🔗

    Example 48.

    Determine the number and type of solutions for:
    🔗
    \begin{equation*} 5x^2 - 3x + 1 = 0 \end{equation*}
    Solution.
    Here \(a = 5\text{,}\) \(b = -3\text{,}\) \(c = 1\text{.}\)
    🔗
    \begin{equation*} D = b^2 - 4ac = (-3)^2 - 4(5)(1) = 9 - 20 = -11 \end{equation*}
    Since \(-11 < 0\text{,}\) there are 2 complex solutions.
    🔗
