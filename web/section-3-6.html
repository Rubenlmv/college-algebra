    Section Section 3.6 Polynomial and Rational Inequalities

    Subsection Polynomial and Rational Inequalities

    Polynomial and Rational Inequalities Video
    🔗
    An inequality that can be written in the form
    \begin{equation*} f(x) < 0,\quad f(x) > 0,\quad f(x) \leq 0,\quad f(x) \geq 0 \end{equation*}
    where \(f(x)\) is a polynomial is called a polynomial inequality. If \(f(x)\) is a rational function, it is called a rational inequality.
    🔗
    Why do we require that one side be 0?
    🔗
    Remember:
    • If \(f(x) > 0\text{,}\) the graph is above the \(x\)-axis.
      🔗
    • If \(f(x) < 0\text{,}\) the graph is below the \(x\)-axis.
      🔗
    • If \(f(x) = 0\text{,}\) the graph is on the \(x\)-axis (these are the zeros).
      🔗
    🔗
    How does this help us?
    🔗
    Consider a point on the graph, \((a,b)\text{.}\) If the the point is above the \(x\)-axis, then we know two important facts:
    🔗
    1. \(f(a) > 0\text{.}\)
      🔗
    2. \(f(x)>0\) for \(x\)-values close to \(a\text{.}\)
      🔗
    🔗

    Subsection The Sign Chart Method

    Consider a continuous function \(f(x)\text{.}\) If we know the zeros of the function (where \(f(x)=0\)), we can use the fact that a continuous function can only change sign at a zero or at a vertical asymptote.
    🔗
    Therefore, if we pick any point \(x = a\) in an interval between two consecutive zeros, the output \(f(a)\) will have the same sign as every other point in that interval. This is the fundamental idea behind the sign chart method.
    🔗
    For rational functions, the sign of \(f(x)\) can also change at undefined values (vertical asymptotes). Therefore, the process for rational inequalities involves finding both the zeros and the values that are not in the domain (where the denominator is zero).
    🔗
    The Sign Chart Method:
    🔗
    Step 1: Move all terms to one side so the other side is \(0\text{.}\) Define \(f(x)\) and state the inequality to be solved (e.g., \(f(x) \leq 0\)).
    🔗
    Step 2: Find the boundary points. These are the zeros of \(f(x)\) and any undefined values (points not in the domain).
    🔗
    • Zeros: solve \(f(x)=0\) (for rational functions, solve the numerator = 0).
      🔗
    • Undefined values: set the denominator = 0 and solve.
      🔗
    Step 3: Choose a test point in each interval. The boundary points divide the real number line into intervals. Pick a convenient test point in each interval and evaluate \(f(x)\text{.}\) Record whether the output is positive or negative.
    🔗
    Step 4: Write the solution.
    🔗
    • If solving \(f(x) > 0\text{,}\) include intervals where \(f(x)\) is positive.
      🔗
    • If solving \(f(x) \geq 0\text{,}\) include intervals where \(f(x)\) is positive and the zeros.
      🔗
    • Never include undefined values.
      🔗
    🔗

    Subsection Example 1: Solving a Quadratic Inequality

    Example 397.

    Solve \(x^2 - 2x \leq 15\text{.}\)
    🔗
    Solution.
    Step 1: Move all terms to one side.
    🔗
    \begin{equation*} x^2 - 2x - 15 \leq 0 \end{equation*}
    Let \(f(x) = x^2 - 2x - 15\text{.}\) We want to know where \(f(x) \leq 0\text{.}\)
    🔗
    Step 2: Find the zeros.
    🔗
    Factor:
    🔗
    \begin{equation*} f(x) = (x - 5)(x + 3) \end{equation*}
    The zeros are \(x = 5\) and \(x = -3\text{.}\) These are the boundary points.
    🔗
    Step 3: Choose test points.
    🔗
    The zeros divide the number line into three intervals:
    🔗
    • \(\displaystyle (-\infty, -3)\)
      🔗
    • \(\displaystyle (-3, 5)\)
      🔗
    • \(\displaystyle (5, \infty)\)
      🔗
    We choose a test point in each interval: \(x = -5\text{,}\) \(x = 0\text{,}\) and \(x = 6\text{.}\)
    🔗
    Evaluate \(f(x)\) at each test point:
    🔗
    • At \(x = -5\text{:}\) \(f(-5) = (-5)^2 - 2(-5) - 15 = 25 + 10 - 15 = 20\) → positive.
      🔗
    • At \(x = 0\text{:}\) \(f(0) = 0 - 0 - 15 = -15\) → negative.
      🔗
    • At \(x = 6\text{:}\) \(f(6) = 36 - 12 - 15 = 9\) → positive.
      🔗
    Step 4: Write the solution.
    🔗
    Since we want \(f(x) \leq 0\text{,}\) we choose the interval where \(f(x)\) is negative. We also include the zeros because the inequality is non-strict (\(\leq\)).
    🔗
    The solution is \(-3 \leq x \leq 5\text{.}\)
    🔗
    In interval notation: \([-3, 5]\text{.}\)
    🔗
    🔗
    🔗
    🔗

    Subsection Example 2: Solving a Quadratic Inequality

    Example 400.

    Solve \(-x^2 - x + 6 > 0\text{.}\)
    🔗
    Solution.
    Step 1: Let \(f(x) = -x^2 - x + 6\text{.}\) We want \(f(x) > 0\text{.}\)
    🔗
    Step 2: Find the zeros.
    🔗
    Factor:
    🔗
    \begin{equation*} f(x) = -(x^2 + x - 6) = -(x + 3)(x - 2) \end{equation*}
    The zeros are \(x = -3\) and \(x = 2\text{.}\)
    🔗
    Step 3: Choose test points.
    🔗
    The zeros divide the number line into three intervals:
    🔗
    • \(\displaystyle (-\infty, -3)\)
      🔗
    • \(\displaystyle (-3, 2)\)
      🔗
    • \(\displaystyle (2, \infty)\)
      🔗
    Choose test points: \(x = -4\text{,}\) \(x = 0\text{,}\) and \(x = 3\text{.}\)
    🔗
    • At \(x = -4\text{:}\) \(f(-4) = -(-4)^2 - (-4) + 6 = -16 + 4 + 6 = -6\) → negative.
      🔗
    • At \(x = 0\text{:}\) \(f(0) = 6\) → positive.
      🔗
    • At \(x = 3\text{:}\) \(f(3) = -9 - 3 + 6 = -6\) → negative.
      🔗
    Step 4: Write the solution.
    🔗
    Since we want \(f(x) > 0\text{,}\) we choose the interval where \(f(x)\) is positive. We do not include the zeros because the inequality is strict (\(>\)).
    🔗
    The solution is \(-3 < x < 2\text{.}\)
    🔗
    In interval notation: \((-3, 2)\text{.}\)
    🔗
    🔗
    🔗
    Video Examples
    🔗

    Example 402.

    Solve \(-(x + 4)^2(x - 3) > 0\text{.}\)
    🔗
    Solution.
    Step 1: Let \(f(x) = -(x + 4)^2(x - 3)\text{.}\) We want \(f(x) > 0\text{.}\)
    🔗
    Step 2: Find the zeros.
    🔗
    The zeros are \(x = -4\) (multiplicity 2) and \(x = 3\) (multiplicity 1). Note that a zero with even multiplicity does not cause a sign change.
    🔗
    Step 3: Choose test points.
    🔗
    The zeros divide the number line into three intervals:
    🔗
    • \(\displaystyle (-\infty, -4)\)
      🔗
    • \(\displaystyle (-4, 3)\)
      🔗
    • \(\displaystyle (3, \infty)\)
      🔗
    Choose test points: \(x = -5\text{,}\) \(x = -2\text{,}\) and \(x = 4\text{.}\)
    🔗
    • At \(x = -5\text{:}\) \(f(-5) = -(-1)^2(-8) = -(1)(-8) = 8\) → positive.
      🔗
    • At \(x = -2\text{:}\) \(f(-2) = -(2)^2(-5) = -(4)(-5) = 20\) → positive.
      🔗
    • At \(x = 4\text{:}\) \(f(4) = -(8)^2(1) = -64\) → negative.
      🔗
    Step 4: Write the solution.
    🔗
    We want \(f(x) > 0\text{,}\) so we take the intervals where the function is positive: \((-\infty, -4) \cup (-4, 3)\text{.}\)
    🔗
    Note that \(x = -4\) is not included because it makes the function equal to 0, not greater than 0.
    🔗
    In interval notation: \((-\infty, -4) \cup (-4, 3)\text{.}\)
    🔗
    🔗
    🔗

    Subsection Example: Solving a Rational Inequality

    Video Examples
    🔗

    Example 404.

    Solve \(\frac{x^2 + 8x + 12}{x - 1} \geq 0\text{.}\)
    🔗
    Solution.
    Step 1: Let \(f(x) = \frac{x^2 + 8x + 12}{x - 1}\text{.}\) We want \(f(x) \geq 0\text{.}\)
    🔗
    Step 2: Find the boundary points.
    🔗
    Factor the numerator:
    🔗
    \begin{equation*} x^2 + 8x + 12 = (x + 6)(x + 2) \end{equation*}
    Zeros (where numerator = 0): \(x = -6\) and \(x = -2\text{.}\)
    🔗
    Undefined values (where denominator = 0): \(x = 1\text{.}\)
    🔗
    Step 3: Choose test points.
    🔗
    The boundary points divide the number line into four intervals:
    🔗
    • \(\displaystyle (-\infty, -6)\)
      🔗
    • \(\displaystyle (-6, -2)\)
      🔗
    • \(\displaystyle (-2, 1)\)
      🔗
    • \(\displaystyle (1, \infty)\)
      🔗
    Choose test points: \(x = -7\text{,}\) \(x = -4\text{,}\) \(x = 0\text{,}\) and \(x = 2\text{.}\)
    🔗
    Evaluate \(f(x)\) at each test point:
    🔗
    • At \(x = -7\text{:}\) \(f(-7) = \frac{(-1)(-5)}{-8} = \frac{5}{-8}\) → negative.
      🔗
    • At \(x = -4\text{:}\) \(f(-4) = \frac{(2)(-2)}{-5} = \frac{-4}{-5}\) → positive.
      🔗
    • At \(x = 0\text{:}\) \(f(0) = \frac{(6)(2)}{-1} = \frac{12}{-1}\) → negative.
      🔗
    • At \(x = 2\text{:}\) \(f(2) = \frac{(8)(4)}{1} = 32\) → positive.
      🔗
    Step 4: Write the solution.
    🔗
    Since we want \(f(x) \geq 0\text{,}\) we choose the intervals where \(f(x)\) is positive. We include the zeros but never include the undefined value.
    🔗
    The solution is \([-6, -2] \cup (1, \infty)\text{.}\)
    🔗
    🔗
    🔗

    Subsection Example: Inequality Not 0 on One Side

    Example Video with Inequality Not 0 on One Side
    🔗

    Example 407.

    Solve \(\frac{x - 3}{x - 2} < 2\text{.}\)
    🔗
    Solution.
    Step 1: Move all terms to one side.
    🔗
    \begin{equation*} \frac{x - 3}{x - 2} - 2 < 0 \end{equation*}
    Combine into a single fraction:
    🔗
    \begin{equation*} \frac{x - 3 - 2(x - 2)}{x - 2} < 0 \end{equation*}
    \begin{equation*} \frac{x - 3 - 2x + 4}{x - 2} < 0 \end{equation*}
    \begin{equation*} \frac{-x + 1}{x - 2} < 0 \end{equation*}
    Let \(f(x) = \frac{-x + 1}{x - 2}\text{.}\) We want \(f(x) < 0\text{.}\)
    🔗
    Step 2: Find the boundary points.
    🔗
    Zero (numerator = 0): \(x = 1\text{.}\)
    🔗
    Undefined value (denominator = 0): \(x = 2\text{.}\)
    🔗
    Step 3: Choose test points.
    🔗
    The boundary points divide the number line into three intervals:
    🔗
    • \(\displaystyle (-\infty, 1)\)
      🔗
    • \(\displaystyle (1, 2)\)
      🔗
    • \(\displaystyle (2, \infty)\)
      🔗
    Choose test points: \(x = 0\text{,}\) \(x = 1.5\text{,}\) and \(x = 3\text{.}\)
    🔗
    • At \(x = 0\text{:}\) \(f(0) = \frac{1}{-2} = -0.5\) → negative.
      🔗
    • At \(x = 1.5\text{:}\) \(f(1.5) = \frac{-0.5}{-0.5} = 1\) → positive.
      🔗
    • At \(x = 3\text{:}\) \(f(3) = \frac{-2}{1} = -2\) → negative.
      🔗
    Step 4: Write the solution.
    🔗
    Since we want \(f(x) < 0\text{,}\) we choose the intervals where \(f(x)\) is negative. We do not include the zero and we never include the undefined value.
    🔗
    The solution is \((-\infty, 1) \cup (2, \infty)\text{.}\)
