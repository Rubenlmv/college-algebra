    Section Section 2.3 Functions

    Subsection Introduction to Functions

    Functions Video
    🔗
    A function is a relation between two sets that takes each input to exactly one output.
    🔗
    🔗

    Definition 57. Domain.

    The set of inputs (\(x\)-values) of the relation.
    🔗
    🔗

    Definition 58. Range.

    The set of outputs (\(y\)-values) of the relation.
    🔗
    🔗
    Most functions we work with have names like \(f\text{,}\) \(g\text{,}\) and \(h\text{.}\)
    🔗
    Think of a function as a machine: you put in an \(x\)-value (input), and the machine gives you a corresponding unique \(y\)-value (output).
    🔗
    🔗
    🔗
    In this course, our functions will usually have numerical inputs and outputs. Generally, we use the variable \(x\) to denote input values (though we can use any other letter or symbol), and \(y\) or \(f(x)\) to denote the output values.
    🔗
    So, most of the time we will see expressions like \(f(x)=2x^3-2x\text{.}\)
    🔗
    For our purposes, an alternative definition of a function is the following:
    🔗

    Definition 60. Function.

    A function is an equation for which any input \(x\) yields exactly one output \(y\text{.}\)
    🔗
    🔗
    🔗

    Subsection Function Notation

    • \(f\) is the name of the function (it could be \(f\text{,}\) \(g\text{,}\) \(h\text{,}\) \(F\text{,}\) \(G\text{,}\) or another letter)
      🔗
    • \(x\) is the input (independent variable) from the domain
      🔗
    • \(f(x)\) is the output (or \(y\)-value) for the corresponding \(x\)
      🔗
    We read \(f(x) = 3x^2 - 4\) as “f of x equals 3 x squared minus 4”.
    🔗
    With function notation from Figure 59, we can write \(f(\text{Bob}) = 21\text{,}\) meaning that the function \(f = \text{age}\) takes Bob and assigns him the age 21.
    🔗
    The function that takes any number and assigns its square is represented by the equation:
    🔗
    \begin{equation*} f(x) = x^2 \end{equation*}
    For instance, \(f(2) = 2^2 = 4\) and \(f(-1) = (-1)^2 = 1\text{.}\)
    🔗
    🔗

    Subsection Evaluating Functions

    Evaluating Functions Video
    🔗
    When evaluating functions for specific inputs, replace \(x\) with parentheses. Then substitute the number and simplify. Don’t forget the order of operations.
    🔗

    Example 90.

    Let \(f(x) = 2x - 3x^2\) and \(g(x) = \dfrac{2x^2 + 1}{4x}\)
    🔗
    Find:
    🔗
    a. \(f(2)\)
    🔗
    b. \(g(3)\)
    🔗
    c. \(f(-4)\)
    🔗
    d. \(g(-2)\)
    🔗
    Solution.
    a. \(f(2) = 2(2) - 3(2)^2 = 4 - 12 = -8\)
    🔗
    b. \(g(3) = \dfrac{2(3)^2 + 1}{4(3)} = \dfrac{18 + 1}{12} = \dfrac{19}{12}\)
    🔗
    c. \(f(-4) = 2(-4) - 3(-4)^2 = -8 - 48 = -56\)
    🔗
    d. \(g(-2) = \dfrac{2(-2)^2 + 1}{4(-2)} = \dfrac{8 + 1}{-8} = -\dfrac{9}{8}\)
    🔗
    🔗
    🔗
    🔗
    Recall that given a function we can draw its graph by plotting points (ordered pairs) \((x,f(x))\text{.}\) For instance we saw the graph of the function \(f(x)=𝑥^2 +3\) in Example 80.
    🔗
    Conversely, giving a graph we can determine whether it corresponds to a function or not, and if it does, we can find its domain and range from it.
    🔗

    Subsection Vertical Line Test

    Vertical Line Test Video
    🔗
    By the definition of a function, at most one \(y\)-value corresponds to a given \(x\)-value.
    🔗
    This means that the graph of a function cannot have two or more different points with the same \(x\)-coordinate, and no two points on the graph of a function can be vertically above or below each other.
    🔗
    It follows, then, that a vertical line can intersect the graph of a function at most once.
    🔗

    Problem-Solving Strategy 61. Vertical Line Test for Functions.

    If any vertical line intersects the graph in more than one point, the graph does not represent a function. If every vertical line intersects the graph in at most one point, the graph represents a function.
    🔗
    🔗

    Example 91.

    Which graphs are functions? Use the vertical line test.
    🔗
    Solution.
    Use the vertical line test: if a vertical line intersects the graph more than once, it is not a function.
    🔗
    The results are:
    🔗
    • a. \(y = \frac12 x^2\) is a function – every vertical line intersects the parabola exactly once.
      🔗
    • b. \(x - y^2 = 1\) is not a function – vertical lines intersect the graph twice (shown by the red dots).
      🔗
    • c. \(y = \frac14 x^3\) is a function – every vertical line intersects the cubic exactly once.
      🔗
    • d. \(x^2 = 2xy - 1\) is a function – solving for \(y\) gives \(y = \frac{x^2+1}{2x}\text{,}\) which yields exactly one \(y\) for each \(x \neq 0\text{.}\)
      🔗
    🔗
    🔗
    🔗

    Subsection Domain and Range from Graphs

    Domain and Range Video
    🔗
    Functions can be defined by graphs (without an equation). The function is still the collection of ordered pairs \((x, f(x))\text{.}\) That means we can use the graph to find the domain and range.
    🔗

    Example 92.

    Find the domain and range of each graph shown.
    🔗
    Solution.
    For each graph, determine the set of all possible \(x\)-values (domain) and the set of all possible \(y\)-values (range).
    🔗
    The solutions are:
    🔗
    • a. Domain: \([-2, 2)\text{,}\) Range: \([0, 2]\text{.}\)
      🔗
    • b. Domain: \((-\infty, \infty)\text{,}\) Range: \([0, \infty)\text{.}\)
      🔗
    • c. Domain: \((-\infty, 1) \cup (1, \infty)\text{,}\) Range: \(\{-1, 2\}\text{.}\)
      🔗
    • d. Domain: \((-\infty, 1) \cup [2, \infty)\text{,}\) Range: \([1, \infty)\text{.}\)
      🔗
    🔗
    🔗
    🔗

    Subsection Finding Domain Algebraically

    When finding the domain of a function without a graph, watch out for these trouble areas:
    🔗

    Problem-Solving Strategy 67. Finding Domain Algebraically.

    The domain of a function \(f\) is the set of all the \(x\)-values for which we can compute \(f(x)\text{.}\) Hence, when the function has fractions or radicals, we must exclude some values.
    🔗
    1. Exclude values of \(x\) that make the denominator zero. (Set the denominator \(\ne 0\))
      🔗
    2. When the index of the root is even, exclude values of \(x\) that make the radicand negative. (Set stuff under root \(\ge 0\))
      🔗
    🔗

    Example 93.

    Find the domain of each function:
    🔗
    a. \(f(x) = \dfrac{x + 2}{x^2 - 2x - 8}\)
    🔗
    b. \(f(x) = \dfrac{x + 6}{x^2 + 12x + 36}\)
    🔗
    c. \(f(x) = \dfrac{x - 5}{x^2 + 4}\)
    🔗
    d. \(f(x) = \dfrac{1}{\sqrt{x - 2}}\)
    🔗
    Solution.
    a.
    \begin{equation*} x^2 - 2x - 8 \ne 0 \Rightarrow (x - 4)(x + 2) \ne 0 \Rightarrow x \ne 4, -2 \end{equation*}
    🔗
    Domain: \((-\infty, -2) \cup (-2, 4) \cup (4, \infty)\)
    🔗
    b.
    \begin{equation*} x^2 + 12x + 36 \ne 0 \Rightarrow (x + 6)^2 \ne 0 \Rightarrow x \ne -6 \end{equation*}
    🔗
    Domain: \((-\infty, -6) \cup (-6, \infty)\)
    🔗
    c. \(x^2 + 4\) is always positive, so no restrictions.
    🔗
    Domain: \((-\infty, \infty)\)
    🔗
    d. Need \(x - 2 > 0\) (since denominator cannot be zero).
    🔗
    Domain: \((2, \infty)\)
    🔗
    🔗
    🔗
    🔗

    Subsection Zeros of a Function

    Zeros of a Function Video
    🔗
    If the graph of a function of \(x\) has an \(x\)-intercept at \((a, 0)\text{,}\) then \(a\) is a zero of the function.
    🔗

    Problem-Solving Strategy 72. Zeros of a Function.

    To find the zeros of a function \(f\text{,}\) solve the equation \(f(x) = 0\text{.}\)
    🔗
    🔗
    When we talk about zeros of a function, this also means:
    🔗
    • \(x = a\) is a zero of function \(f\)
      🔗
    • \(x = a\) is a solution of \(f(x) = 0\)
      🔗
    • \((a, 0)\) is an \(x\)-intercept of the graph of \(f(x)\)
      🔗

    Example 94.

    Find the zeros of each function.
    🔗
    a. \(f(x) = 3x^2 + x - 10\)
    🔗
    b. \(g(x) = \sqrt{25 - x^2}\)
    🔗
    c. \(h(x) = \dfrac{2x - 4}{x + 1}\)
    🔗
    Solution.
    a. Set \(f(x) = 0\text{:}\)
    🔗
    \begin{equation*} 3x^2 + x - 10 = 0 \end{equation*}
    \begin{equation*} (3x - 5)(x + 2) = 0 \end{equation*}
    \begin{equation*} x = \frac{5}{3} \quad \text{or} \quad x = -2 \end{equation*}
    Zeros: \(x = \frac{5}{3}, -2\)
    🔗
    b. Set \(g(x) = 0\text{:}\)
    🔗
    \begin{equation*} \sqrt{25 - x^2} = 0 \end{equation*}
    \begin{equation*} 25 - x^2 = 0 \end{equation*}
    \begin{equation*} x^2 = 25 \end{equation*}
    \begin{equation*} x = \pm 5 \end{equation*}
    Zeros: \(x = -5, 5\)
    🔗
    c. Set \(h(x) = 0\text{:}\)
    🔗
    \begin{equation*} \frac{2x - 4}{x + 1} = 0 \end{equation*}
    A fraction is zero when the numerator is zero:
    🔗
    \begin{equation*} 2x - 4 = 0 \end{equation*}
    \begin{equation*} x = 2 \end{equation*}
    Zero: \(x = 2\)
    🔗
    🔗
    🔗
    Example: Look again at \(f(x) = 3x^2 + x - 10\text{.}\) We found the zeros by solving:
    🔗
    \begin{equation*} 0 = 3x^2 + x - 10 = (3x - 5)(x + 2) \end{equation*}
    🔗
