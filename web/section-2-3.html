    Section Section 2.3 Functions

    Subsection Introduction to Functions

    Functions Video
    🔗
    A function is a relation that takes each input to exactly one output.
    🔗
    Think of it as a machine: you put in an \(x\)-value (input), and the machine gives you a corresponding unique \(y\)-value (output).
    🔗
    Most functions we work with have names like \(f\text{,}\) \(g\text{,}\) and \(h\text{.}\)
    🔗

    Definition 55. Domain.

    The set of inputs (\(x\)-values) of the relation.
    🔗
    🔗

    Definition 56. Range.

    The set of outputs (\(y\)-values) of the relation.
    🔗
    🔗

    Definition 57. Function.

    A relation in \(x\) and \(y\) where for each value of \(x\) in the domain, there is exactly one corresponding value of \(y\) in the range.
    🔗
    🔗
    🔗

    Subsection Function Notation

    A function may be defined by an equation in two variables. For example, \(y = 3x^2 - 4\) defines \(y\) as a function of \(x\text{,}\) since for any real number \(x\) there is exactly one corresponding value for \(y\text{.}\)
    🔗
    To make it clear that the relation is a function, we use function notation:
    🔗
    \begin{equation*} f(x) = 3x^2 - 4 \end{equation*}
    We read this as “f of x equals 3 x squared minus 4”.
    🔗
    With function notation we know:
    🔗
    • \(f\) is the name of the function (it could be \(f\text{,}\) \(g\text{,}\) \(h\text{,}\) \(F\text{,}\) \(G\text{,}\) or another letter)
      🔗
    • \(x\) is the input (independent variable) from the domain
      🔗
    • \(f(x)\) is the output (or \(y\)-value) for the corresponding \(x\)
      🔗
    The set of inputs is called the domain, and the set of outputs is called the range of the function.
    🔗
    This function could be defined by \(\{(-2, 5), (-1, 2), (0, 1), (1, 2)\}\text{.}\)
    🔗
    🔗

    Subsection Identifying Functions

    Example 88.

    Examples. Which of the following are examples of relations that are functions? Why or why not?
    🔗
    1) \(\{(1, 2), (2, 4), (3, 6), (4, 8)\}\)
    🔗
    2) \(\{(1, 2), (1, 4), (1, 6), (1, 8)\}\)
    🔗
    3) Mapping Diagram:
    🔗
    4) \(y = 3x^2 - 4\)
    🔗
    5) \(x^2 + y^2 = 4\)
    🔗
    Solution.
    Solutions:
    🔗
    1) \(\{(1, 2), (2, 4), (3, 6), (4, 8)\}\) is a function because each \(x\)-value has exactly one corresponding \(y\)-value.
    🔗
    2) \(\{(1, 2), (1, 4), (1, 6), (1, 8)\}\) is not a function because the \(x\)-value \(1\) maps to multiple \(y\)-values.
    🔗
    3) The mapping diagram is not a function because \(-2\) maps to both \(-2\) and \(6\text{.}\)
    🔗
    4) \(y = 3x^2 - 4\) is a function because for each \(x\text{,}\) there is exactly one \(y\)-value.
    🔗
    5) \(x^2 + y^2 = 4\) is not a function because, for example, when \(x = 0\text{,}\) \(y = \pm 2\text{.}\)
    🔗
    🔗
    🔗
    🔗

    Subsection Graphs of Functions

    The graph of a function \(f\) is the collection of ordered pairs \((x, f(x))\) such that \(x\) is in the domain of \(f\text{.}\)
    🔗
    Every \((x, y)\) pair on the graph satisfies \(f(x)\text{.}\)
    🔗

    Example 89.

    Use the graph of \(f(x) = 2x^3 - 4x^2 + 2\) to answer the following:
    🔗
    What is \(f(-1)\text{?}\)
    🔗
    For what value of \(x\text{,}\) does \(f(x) = 0\text{?}\)
    🔗
    Solution.
    \(f(-1) = -4\)
    🔗
    \(f(x) = 0\) when \(x = 1\) (since \((1, 0)\) is on the graph).
    🔗
    🔗
    🔗
    🔗

    Subsection Domain and Range from Graphs

    Domain and Range Video
    🔗
    Functions can be defined by graphs (without an equation). The function is still the collection of ordered pairs \((x, y)\text{.}\) That means we can use the graph to find the domain and range.
    🔗

    Example 90.

    Find the domain and range of each graph shown.
    🔗
    Solution.
    a. Domain: \([-2, 2]\text{,}\) Range: \([0, 4]\)
    🔗
    b. Domain: \((-∞, ∞)\text{,}\) Range: \((-∞, ∞)\)
    🔗
    c. Domain: \((-∞, 1) \cup [1, ∞)\) (with open/closed mixed), Range: \([-3, -1) \cup (-1, ∞)\)
    🔗
    d. Domain: \((-∞, ∞)\text{,}\) Range: \((-∞, ∞)\)
    🔗
    🔗
    🔗
    🔗

    Subsection Finding Domain Algebraically

    When finding the domain of a function without a graph, watch out for these trouble areas:
    🔗

    Problem-Solving Strategy 64. Finding Domain Algebraically.

    1. Denominators cannot equal zero. (Set the denominator \(\ne 0\))
      🔗
    2. Even radicands must not be negative. (Stuff under even root \(\ge 0\))
      🔗
    🔗

    Example 91.

    Find the domain of each function:
    🔗
    a. \(f(x) = \dfrac{x + 2}{x^2 - 2x - 8}\)
    🔗
    b. \(f(x) = \dfrac{x + 6}{x^2 + 12x + 36}\)
    🔗
    c. \(f(x) = \dfrac{x - 5}{x^2 + 4}\)
    🔗
    d. \(f(x) = \dfrac{1}{\sqrt{x - 2}}\)
    🔗
    Solution.
    a. \(x^2 - 2x - 8 \ne 0 \Rightarrow (x - 4)(x + 2) \ne 0 \Rightarrow x \ne 4, -2\)
    🔗
    Domain: \((-\infty, -2) \cup (-2, 4) \cup (4, \infty)\)
    🔗
    b. \(x^2 + 12x + 36 \ne 0 \Rightarrow (x + 6)^2 \ne 0 \Rightarrow x \ne -6\)
    🔗
    Domain: \((-\infty, -6) \cup (-6, \infty)\)
    🔗
    c. \(x^2 + 4\) is always positive, so no restrictions.
    🔗
    Domain: \((-\infty, \infty)\)
    🔗
    d. Need \(x - 2 > 0\) (since denominator cannot be zero).
    🔗
    Domain: \((2, \infty)\)
    🔗
    🔗
    🔗
    🔗

    Subsection Vertical Line Test

    Vertical Line Test Video
    🔗
    By the definition of a function, at most one \(y\)-value corresponds to a given \(x\)-value.
    🔗
    This means that the graph of a function cannot have two or more different points with the same \(x\)-coordinate, and no two points on the graph of a function can be vertically above or below each other.
    🔗
    It follows, then, that a vertical line can intersect the graph of a function at most once.
    🔗

    Problem-Solving Strategy 65. Vertical Line Test for Functions.

    A set of points in a coordinate plane is the graph of \(y\) as a function of \(x\) if and only if no vertical line intersects the graph at more than one point.
    🔗
    🔗

    Example 92.

    Which graphs are functions? Use the vertical line test.
    🔗
    Solution.
    a. \(y = \frac12 x^2\) is a function (parabola opens up).
    🔗
    b. \(x - y^2 = 1\) is not a function (fails vertical line test).
    🔗
    c. \(y = \frac14 x^3\) is a function (cubic function).
    🔗
    d. \(x^2 = 2y - 1\) is a function (can be written as \(y = \frac{x^2+1}{2}\)).
    🔗
    🔗
    🔗
    🔗

    Subsection Evaluating Functions

    Evaluating Functions Video
    🔗
    When evaluating functions for specific inputs, replace \(x\) with parentheses. Then input your number and simplify. Don’t forget the order of operations.
    🔗

    Example 93.

    Let \(f(x) = 2x - 3x^2\) and \(g(x) = \dfrac{2x^2 + 1}{4x}\)
    🔗
    Find:
    🔗
    a. \(f(2)\)
    🔗
    b. \(g(3)\)
    🔗
    c. \(f(-4)\)
    🔗
    d. \(g(-2)\)
    🔗
    Solution.
    a. \(f(2) = 2(2) - 3(2)^2 = 4 - 12 = -8\)
    🔗
    b. \(g(3) = \dfrac{2(3)^2 + 1}{4(3)} = \dfrac{18 + 1}{12} = \dfrac{19}{12}\)
    🔗
    c. \(f(-4) = 2(-4) - 3(-4)^2 = -8 - 48 = -56\)
    🔗
    d. \(g(-2) = \dfrac{2(-2)^2 + 1}{4(-2)} = \dfrac{8 + 1}{-8} = -\dfrac{9}{8}\)
    🔗
    🔗
    🔗
    🔗

    Subsection Zeros of a Function

    Zeros of a Function Video
    🔗
    If the graph of a function of \(x\) has an \(x\)-intercept at \((a, 0)\text{,}\) then \(a\) is a zero of the function.
    🔗

    Problem-Solving Strategy 67. Zeros of a Function.

    The zeros of a function \(f\) of \(x\) are the \(x\)-values for which \(f(x) = 0\text{.}\)
    🔗
    🔗
    When we talk about zeros of a function, this also means:
    🔗
    • \(x = a\) is a zero of function \(f\)
      🔗
    • \(x = a\) is a solution of \(f(x) = 0\)
      🔗
    • \((a, 0)\) is an \(x\)-intercept of the graph of \(f(x)\)
      🔗

    Example 94.

    Find the zeros of each function.
    🔗
    a. \(f(x) = 3x^2 + x - 10\)
    🔗
    b. \(g(x) = \sqrt{25 - x^2}\)
    🔗
    c. \(h(x) = \dfrac{2x - 4}{x + 1}\)
    🔗
    Solution.
    a. Set \(f(x) = 0\text{:}\)
    🔗
    \begin{equation*} 3x^2 + x - 10 = 0 \end{equation*}
    \begin{equation*} (3x - 5)(x + 2) = 0 \end{equation*}
    \begin{equation*} x = \frac{5}{3} \quad \text{or} \quad x = -2 \end{equation*}
    Zeros: \(x = \frac{5}{3}, -2\)
    🔗
    b. Set \(g(x) = 0\text{:}\)
    🔗
    \begin{equation*} \sqrt{25 - x^2} = 0 \end{equation*}
    \begin{equation*} 25 - x^2 = 0 \end{equation*}
    \begin{equation*} x^2 = 25 \end{equation*}
    \begin{equation*} x = \pm 5 \end{equation*}
    Zeros: \(x = -5, 5\)
    🔗
    c. Set \(h(x) = 0\text{:}\)
    🔗
    \begin{equation*} \frac{2x - 4}{x + 1} = 0 \end{equation*}
    A fraction is zero when the numerator is zero:
    🔗
    \begin{equation*} 2x - 4 = 0 \end{equation*}
    \begin{equation*} x = 2 \end{equation*}
    Zero: \(x = 2\)
    🔗
    🔗
    🔗
    Example: Look again at \(f(x) = 3x^2 + x - 10\text{.}\) We found the zeros by solving:
    🔗
    \begin{equation*} 0 = 3x^2 + x - 10 = (3x - 5)(x + 2) \end{equation*}
    🔗
    🔗
