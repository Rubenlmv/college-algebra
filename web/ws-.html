    Section Math 1320 Section 1.1

    Subsection Idea 1 – Linear Equations

    Linear equations are also known as equations of first degree. That is, variables have no exponents.
    🔗
    In General, this would exclude equations with variables in the denominators of fractions, since they would have an exponent of \(-1\text{.}\) However, we will see some equations with variables in their denominators that are equivalent to linear equations.
    🔗
    🔗

    Subsection Idea 2 – Solving Equations

    To solve an equation means to find all possible solutions.
    🔗
    Good News! When solving an equation you can do anything you want—as long as you do it twice. Once to the whole left side and once to the whole right side.
    🔗
    The most common things we do:
    • Add/subtract same value from both sides
      🔗
    • Multiply/divide both sides by the same non-zero value
      🔗
    🔗
    We solve equations by:
    1. Distribute to eliminate parentheses
      🔗
    2. Combine "Like Terms"
      🔗
    3. Use Addition/Subtraction to "collect" variables on one side, constants on the other
      🔗
    4. Use Multiplication/Division to isolate the variable
      🔗
    🔗
    🔗

    Subsection Example

    Example 1.
    Solve:
    🔗
    \begin{equation*} x - 4(x - 5) = 2 - (2 - x) \end{equation*}
    Solution.
    Step 1: Distribute on both sides
    🔗
    \begin{equation*} x - 4x + 20 = 2 - 2 + x \end{equation*}
    \begin{equation*} -3x + 20 = x \end{equation*}
    Step 2: Collect variables on one side
    🔗
    \begin{equation*} -3x - x = -20 \end{equation*}
    \begin{equation*} -4x = -20 \end{equation*}
    Step 3: Isolate the variable
    🔗
    \begin{equation*} x = 5 \end{equation*}
    Therefore, the solution is \(x = 5\text{.}\)
    🔗
    🔗
    🔗
    🔗

    Subsection Clearing Fractions

    To clear fractions from an equation:
    1. Find the Lowest Common Denominator (LCD) of ALL the fractions. (If you can’t find the lowest common denominator, just multiply all denominators together.)
      🔗
    2. Multiply every term (on BOTH sides) by the LCD
      🔗
    3. Simplify each term. There should be no fractions.
      🔗
    4. Solve the new equation using your algebra skills.
      🔗
    🔗
    🔗

    Subsection Example

    Example 3.
    Solve:
    🔗
    \begin{equation*} \frac{2x}{3} - \frac{5x}{6} - 3 = \frac{x}{2} - 5 \end{equation*}
    Solution.
    LCD = \(6\)
    🔗
    Step 1: Multiply every term by 6
    🔗
    \begin{equation*} 6\left(\frac{2x}{3}\right) - 6\left(\frac{5x}{6}\right) - 6(3) = 6\left(\frac{x}{2}\right) - 6(5) \end{equation*}
    Step 2: Simplify
    🔗
    \begin{equation*} 4x - 5x - 18 = 3x - 30 \end{equation*}
    \begin{equation*} -x - 18 = 3x - 30 \end{equation*}
    Step 3: Solve
    🔗
    \begin{equation*} -x - 3x = -30 + 18 \end{equation*}
    \begin{equation*} -4x = -12 \end{equation*}
    \begin{equation*} x = 3 \end{equation*}
    Therefore, the solution is \(x = 3\text{.}\)
    🔗
    🔗
    🔗

    Subsection What happens if there is a variable in the denominator?

    Example 4.
    Solve:
    \begin{equation*} \frac{9}{4} - \frac{1}{2x} = \frac{4}{x} \end{equation*}
    🔗
    LCD: Restricted Values for \(x\text{:}\)
    🔗
    Solution.
    LCD = \(4x\)
    🔗
    Restricted Values: \(x \neq 0\)
    🔗
    Step 1: Multiply every term by \(4x\)
    🔗
    \begin{equation*} 4x\left(\frac{9}{4}\right) - 4x\left(\frac{1}{2x}\right) = 4x\left(\frac{4}{x}\right) \end{equation*}
    Step 2: Simplify
    🔗
    \begin{equation*} 9x - 2 = 16 \end{equation*}
    Step 3: Solve
    🔗
    \begin{equation*} 9x = 18 \end{equation*}
    \begin{equation*} x = 2 \end{equation*}
    Since \(2 \neq 0\text{,}\) this is a valid solution.
    🔗
    Therefore, the solution is \(x = 2\text{.}\)
    🔗
    🔗
    🔗
    Example 5.
    Solve:
    \begin{equation*} \frac{1}{x-1} + \frac{x+1}{x^2 + 2x - 3} = \frac{1}{x+3} \end{equation*}
    🔗
    LCD: Restricted Values for \(x\text{:}\)
    🔗
    Solution.
    First, factor \(x^2 + 2x - 3 = (x-1)(x+3)\)
    🔗
    LCD = \((x-1)(x+3)\)
    🔗
    Restricted Values: \(x \neq 1\) and \(x \neq -3\)
    🔗
    Step 1: Multiply every term by \((x-1)(x+3)\)
    🔗
    \begin{equation*} (x-1)(x+3)\left(\frac{1}{x-1}\right) + (x-1)(x+3)\left(\frac{x+1}{(x-1)(x+3)}\right) = (x-1)(x+3)\left(\frac{1}{x+3}\right) \end{equation*}
    Step 2: Simplify
    🔗
    \begin{equation*} (x+3) + (x+1) = (x-1) \end{equation*}
    \begin{equation*} x + 3 + x + 1 = x - 1 \end{equation*}
    \begin{equation*} 2x + 4 = x - 1 \end{equation*}
    \begin{equation*} 2x - x = -1 - 4 \end{equation*}
    \begin{equation*} x = -5 \end{equation*}
    Since \(-5 \neq 1\) and \(-5 \neq -3\text{,}\) this is a valid solution.
    🔗
    Therefore, the solution is \(x = -5\text{.}\)
    🔗
    🔗
    🔗
